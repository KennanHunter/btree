## Packages

- **`core/`** the B-tree itself. Written in pure TypeScript with no dependencies. It emits structured events like split, merge, and rotate for the rest of the stack to consume.

  ```
  pnpm --filter core test
  ```

- **`component/`** a SolidJS component that renders a tree and animates between states off of `core`'s event stream. All the keyframe choreography and easing lives there.

  ```
  pnpm --filter component test
  ```

- **`vis/`** the interactive visualizer app. Dev panel, event log, playback controls.

  ```
  pnpm --filter vis dev
  ```

- **`benchmark/`** workload generators and a CLI for running them against `core`.

  ```
  pnpm --filter benchmark bench
  ```

- **`video-recorder/`** drives `vis` through Playwright to record the animation as a webp.

  ```
  git add .
  ```

- **`rust/btree/`** a from-scratch Rust reimplementation, meant for timing and cache benchmarks. Not wired into the JS packages.

  ```
  cargo test
  ```
